# TrustTrail 🧭
### Explore with confidence. Travel with clarity.

**TrustTrail** is a travel-information and destination-planning website designed to help travellers explore destinations with confidence through practical guidance, transparent sources, and destination information.

## About the Project

TrustTrail is an original concept by **Lavender Akinyi**. The project aims to help travellers make more informed decisions by bringing important destination information together in one place.

The initial prototype focuses on three attractions in Kenya:

- **Meru National Park** — nature and wildlife.
- **Mount Kenya National Park** — mountain scenery and hiking.
- **Meru Museum** — cultural heritage and local history.

## Key Features

- Destination discovery and filtering.
- Travel information and route-planning guidance.
- Destination comparison.
- Source transparency and information-status indicators.
- Saved destinations
